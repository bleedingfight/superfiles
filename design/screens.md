# 画面清单（Figma 摆稿顺序书）

按依赖排序；每屏先画默认态，再补状态变体。iOS / Android 并排两幅，强迫一致性核查；
TV 屏单独一节（焦点模型见 docs/06 §5）。

## 第一批：M1「可用」（最优先，因为接下去就写它）

### 1. 文件浏览（已有 M0，重画对稿）
- 组件：AppBar(标题+返回) / SearchField / FileRow / FAB(索引) / Footer(计数)
- 变体：空态、加载中、错误 Snackbar、长按选中（**新增**：多选模式 AppBar 替换）

### 2. 冲突对话框（新增）
- 触发：复制时目标已存在
- 结构：文件名 + 三个操作（覆盖/跳过/重命名）+ 「全部应用」勾选
- 状态：单次 / 批量第 N 项

### 3. 传输中心（新增）
- 组件：TransferRow（文件名、进度条、(速率/剩余) 、暂停/取消）、空态、错误重试态
- 入口：AppBar 图标 / 通知点（Android 通知栏另出一张）

### 4. 设置（新增，骨架）
- 项：索引状态、缓存清理、主题（跟随系统/浅/深）、关于
- TV 端设置 = 左侧导航抽屉版（见 TV 节）

## 第二批：M2「网络存储」

### 5. 连接向导（关键新流程，先画流程图再画屏）
- 步骤：选类型(SMB/WebDAV/SFTP) → 填主机/账户 → 测试连接(进行中/失败原因) → 命名挂载
- 状态变体：认证失败、超时、能力降级提示（如 WebDAV 只读）
- 组件：ServerTypeCard / FormField / WizardProgress

### 6. 我的连接（Server 列表）
- ServerCard：协议图标 + 名称 + host + 状态点(在线/离线) + 滑动操作(编辑/删除)

### 7. 远端浏览
- 复用 FileRow；AppBar 加连接状态点；弱网重连横幅（非模态）

## 第三批：TV（10 英尺体验单独对稿）

### 8. TV 首屏（横向卡片流）
- 焦点首落点 = 左上角第一个卡片（合同）
- 组件：FocusCard（无焦点/聚焦两态）、分组标题行
- 安全区：四周 5% overscan inset 标注

### 9. TV 播放
- 播放器控制条（播放/暂停/进度/音轨字幕）聚焦路径自上而下；10s 无操作自动隐藏
