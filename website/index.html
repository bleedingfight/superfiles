一份 Rust 内核，
装进每一个平台原生的文件管理器

Super Files 是跨平台文件管理应用：Swift / Kotlin / ArkTS 只写界面与平台适配， 文件系统、传输引擎、索引搜索全部共享同一份 Rust 内核（通过 UniFFI 暴露）。 离线浏览、断点续传、近邻传输、FTS5+拼音搜索开箱即用。

Architecture

UI 全原生，逻辑全共享

上层是各平台原生 UI（SwiftUI / Jetpack Compose / ArkUI），中间是 UniFFI 自动生成的 Swift / Kotlin / ArkTS 绑定，底层是同一份 Rust 内核。改一处内核，四端同时受益。

原生 UI
apps/androidJetpack Compose（同 APK 支持 TV）
apps/ohosArkTS（HarmonyOS NEXT / TV）
apps/iosSwiftUI（iPhone / iPad 三栏）
apps/kio-workerKDE Dolphin 的 superfiles:// 插件
UniFFI 绑定
bindings/kotlin提交进仓库，Android 直接引用
bindings/arktsuniffi-bindgen-arkts + N-API adapter
bindings/swift生成 Swift 包，构建脚本拷贝
Rust 内核
vfs-core统一虚拟文件系统 + 全部后端
engine传输引擎：预扫描 / 分块 / 进度 / 冲突
indexSQLite 元数据索引 + FTS5 搜索
stream回环 HTTP+Range 媒体流服务
sfiles-ffiUniFFI 出口（三端绑定源）
sfiles-cli桌面 CLI（冒烟 / 调试）

模块布局采用 2018+ 风格（backends.rs + backends/）。 详见 docs/01-architecture.md（分层、线程模型、错误与进度）。

Features

核心功能

以下每一行都是三端（Android / 鸿蒙 / iOS 其中至少两端）已落地的真实功能，差异以三端对照矩阵为准（docs/11）。

🗂️统一 VFS 与 9 大后端

一套 URI 规范 + 能力矩阵，所有后端同一种 API；本地后端带 .. 逃逸防护。

  • 本地：应用沙盒 / 内部共享存储 / 全盘授权（三独立索引库）
  • WebDAV：PROPFIND / Range GET / PUT / 部分写协商 + 受限重试
  • SMB：原生随机读写 / SET_END_OF_FILE / NT 状态码映射 / 断连重挂
  • SFTP：russh 0.55，密码/私钥，断线惰性重连
  • S3：SigV4（MinIO / R2 / OSS），region / pathStyle / 临时令牌
  • 云盘：Google Drive · Dropbox · OneDrive · 115（设备码），OAuth2+PKCE，Keystore/Keychain 加密存令牌

⚡传输引擎

预扫描总量 → 分块复制 → 实时进度；前台浮层 → 后台传输一条龙。

  • 暂停 / 继续：块边界闸门，SQLite checkpoint 断点保持（每 16 chunk 落盘）
  • 冲突对话框：逐项 覆盖 / 跳过 / 重命名 + 全部应用
  • 双缓冲流水线：1 MiB 块，写当前块时预取下一块
  • SMB 根因修复：vendor 补 TCP_NODELAY，单流 5MB/s → 82MiB/s
  • 前台浮层 → 「后台传输」→ FGS / 持续任务 + 通知栏实时进度速度
  • 续传前自动重挂载来源后端（rootId 持久化路由）

🔍索引与搜索

SQLite FTS5 + trigram 分词，中文 / 英文 / 混合子串毫秒级命中。

  • 拼音 sidecar：全拼 + 首字母，大小写不敏感
  • 自然语言查询：「上个月的照片」「大于10MB的pdf」→ 结构化意图
  • locate 式跨根合并搜索：沙盒 + 共享 + 全盘索引并行查询去重
  • 目录「秒开」：FTS 按 rowid 删除 + 后台写线程，5000 条 3.3s → 47ms
  • 离线浏览：实时列举失败回退索引缓存 + 「更新于 X」横幅

🎬流媒体与预览

回环 HTTP+Range 流服务：任意后端媒体直接进系统播放器，不落地。

  • 206 / 416 语义 + token 保护 + 并发 seek（供 ExoPlayer / AVPlayer / Video 组件）
  • 内联预览：图片（缩放/画廊）· 视频（续播位置记忆）· 音频 · 文本 · PDF（按页渲染）
  • 远端文件经流式 Provider 外发打开（打开方式）
  • iPad / 平板宽屏双栏：左列表右预览

📡近邻传输（LocalSend 兼容）

与 LocalSend 协议互通：同一局域网免流量互传。

  • HTTPS 自签证书 + SHA-256 指纹固定（TOFU）
  • 组播发现 + 手动 IP 兜底，一键组网链接 + 二维码
  • 接收端流式落盘：sha256 校验 / 重名避让 / 临时文件清理
  • 收发流水进传输中心「近邻传输」分组

🔗就近分享

选中文件 → 内网「链接 + 二维码」，浏览器免安装直接收。

  • HTML 索引页 + manifest 清单 → 分块拉取经 VFS 落盘
  • token 防枚举，关闭即焚
  • 接收端可落本地或 NAS，重名自动避让

🧹存储清理

空间视角的「传输到本机」+ 本机存储占用两张清单。

  • 完成记录按签名折叠（重试只显示一行），失败展示已写入残余
  • 删记录即删实际文件；批量删除 / 批量移动（走传输引擎）
  • 排序面板：名称 / 时间 / 大小 × 升降序

🧭批量操作与交互

对齐 Figma「栖档」稿的移动端交互基线。

  • 长按多选 + 全选 + 拖拽滑动连续多选 + 底部批量操作条
  • 左滑状态机（传输行）/ 左滑删除 + ⋯ 菜单（文件行）
  • 复制 / 移动统一目标选择器：任意源 ↔ 任意目标（本地 / NAS / 云盘）
  • 压缩（流式 zip + 进度）· 重命名 · 收藏 · 最近打开 · 详情整页

🌐平台体验

一套设计令牌（tokens.json）驱动三端视觉。

  • 三语：简体 / 繁體 / English，Android 13 单应用语言
  • 深色模式（派生草案）、边到边沉浸
  • 横屏 / 平板自适应：600dp 双列、840dp 文件页双栏、NavigationRail
  • 凭据加密：Android Keystore（AES-256-GCM）/ iOS Keychain
